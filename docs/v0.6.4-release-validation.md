# v0.6.4 发布验证报告

验证日期：2026-09-10。状态：**已通过代码、布局与 Windows 发布候选门禁**。验证在隔离的 Electron 测试 `userData` 和发布目录中执行，没有修改现用用户数据。

## 交付范围

- Electron 窗口使用 `titleBarStyle: "hidden"` 和 52px `titleBarOverlay`，页面顶栏与窗口背景融合，保留 Windows 原生最小化、最大化和关闭按钮。
- `.workspace-header` 为拖拽区，“最近操作”为非拖拽交互区；右侧预留窗口按钮安全区，760px 最小宽度下仍不重叠。
- 顶栏使用与工作区相同的暖灰背景、紧凑层级文字、主色状态点和渐隐分隔线，不增加独立的重型标题栏块。
- electron-builder 以本地 `jnu-emblem.svg` 为 Windows 图标源；打包后从主 EXE 和 NSIS 安装器提取的图标 SHA-256 一致。
- 应用、工作区和更新元数据版本升级为 0.6.4；数据库 schema 保持 v4，无数据迁移。
