# 部署 升级与回滚

## 构建

```powershell
npm.cmd ci
npm.cmd run verify
npm.cmd run package:win
```

`electron-builder` 生成 x64 NSIS 安装包。模板通过 `extraResources` 随安装包发布；数据库和导入源文件副本写入 Electron `userData/data`，不写安装目录。默认导出目录和备份目录可在“设置”中更改，数据库目录只读展示，避免运行中搬移 SQLite。

当前开发构建未配置代码签名证书，安装包的 Authenticode 状态为 `NotSigned`。正式分发前应使用组织证书签名，并在目标机验证签名链和 SmartScreen 表现。

## 首次部署

1. 在无 Node、Python、Office 的 Windows 11 x64 验收机安装。
2. 断网启动，导入客户最新排班和成员信息。
3. 按需求 01-28 执行真实验收并记录耗时、系统版本和缩放比例。
4. 完成一次手动备份、一次恢复和一次安装包卸载重装验证。

## 升级

升级前在“设置 > 备份管理”执行“立即备份”。数据库迁移只允许向前追加且在事务中执行；模板版本和哈希随导出批次记录。安装程序不得删除 `userData`。

## 回滚

若新版本启动或迁移失败：

1. 保留失败版本的数据目录副本和日志。
2. 卸载应用但不删除用户数据。
3. 安装上一已验收版本。
4. 如数据库已发生不兼容迁移，从升级前备份恢复并重启应用。

恢复会替换当前数据库，因此无论从备份列表还是其他位置恢复，界面都会先明确提示；恢复前还会自动生成 `pre_restore` 安全备份。
