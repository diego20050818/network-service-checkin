# v0.6.3

本版集中完成签到工作区的响应式修复、可配置班次时段、统一考勤状态与 15 分钟未签到提醒，并补齐轻量页面动效。

## 主要变化

- 签到页移除 1300px 宽度限制，760×540 到 1920×1080 以及 125%/150% 页面缩放均可正常换行。
- 设置页可分别配置 7 条标准班次的开始/结束时间；工时自动计算，符合安全条件的未来正式班次会原子同步。
- 排班模板按当前设置动态生成；周末上午默认修正为 09:00–12:00，Excel 明确时段不再被“上午/下午”覆盖。
- 日历与周视图统一使用灰、绿、红、琥珀状态，并展示每位人员的签到、未签到、待开始或请假标记。
- 签到页增加结束倒计时、首次自动定位、折叠结果和打钩反馈。
- 开班 15 分钟仍未签到会触发一次合并提醒：应用内全窗口动画和提示音；后台增加 Windows 通知及任务栏闪烁。
- 页面切换与细节动效统一为 160–220ms，并完整支持减少动态效果偏好。

## 验证

- TypeScript、21 个测试文件共 79 项、生产构建全部通过。
- Electron E2E 18/18 通过，含 30 张响应式截图与 v0.5.1 实际程序数据升级到 v0.6.3 的逐列对账。
- `npm audit --omit=dev`：0 个已知漏洞。
- Windows x64 NSIS、ASAR、`latest.yml`、SHA-512 和源码清单一致性检查通过。

详细证据与真实环境边界见[发布验证报告](https://github.com/diego20050818/network-service-checkin/blob/v0.6.3/docs/v0.6.3-release-validation.md)。

## 安装提示

安装包尚未配置 Authenticode 代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。125%/150% 自动化场景是 Electron 页面缩放，不等同于 Windows 系统显示缩放实机验收。
