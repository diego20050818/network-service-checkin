# 需求基线索引

本项目实现根目录 `网络服务小组_签到看板与月报导出_需求文档_V2.0.docx` 的首版范围。原文档是最终业务基线；本页用于代码、测试和验收追踪。

## 一句话目标

每天打开软件并选择实际人员签到，系统按班次累计计薪工时；月底填写少量文字与评分，预览后一次导出五类正式文件。

## 首版范围

- Windows 10/11 x64 本机离线 Electron 应用，不需要 Node.js、Python、Office 或数据库服务器。
- 导入三块布局排班与成员资料；正式排班与实际签到分开保存。
- 周末坐班支持按“周六上午、周六下午、周日上午、周日下午”分列并按第 1–5 周填写负责人；上午 08:00–12:00，下午 14:30–17:30。
- 排班单元格为空、待补或空缺时不生成席位，不进入到岗率、未到岗和工时统计。
- 只签到、不签退；`开始 <= 打卡 < 结束` 时计完整班次分钟数。
- 坐班、维修班和周末坐班分别成班，重叠班分别计薪。
- 宽松模式默认不判迟到；迟到模式严格晚于 `开始 + 阈值` 才标迟到，且不扣工时。
- 支持临时替班、更正人员、撤销/恢复误签和带来源的人工补记。
- 签到首页展示当天全部班次、负责人、当前状态和班次结束倒计时。
- 看板展示周班表、负责人到岗状态、计薪工时、到岗率、迟到次数、已结束未签到席位、成员汇总和明细。
- 月报草稿、评分、两名可选推荐、结构化内容预览与五类文件导出。
- 每日首次使用自动备份，保留最近 30 份；支持手动备份和恢复。
- 安装版可由用户开启或关闭 Windows 开机自启动。
- 独立设置页可配置默认月报导出目录与备份目录，并展示应用数据、当前有效排班、最近员工文件和随包输出模板。
- 备份管理展示备份时间、类型、大小和完整性，支持立即备份、从列表恢复及从其他位置恢复。
- “排班与成员”提供空白排班导入模板和空白人员信息模板下载。
- 升级后重新选择相同排班文件时，系统重新解析并补齐缺失班次，不覆盖已有签到。

## 明确不做

签退、早退、实时在岗计时、账号/角色/PIN、审批、自动排班、移动端、云同步、SMTP、发薪转账、税费计算、节假日推断和公平性评价不进入首版。

## 五类输出

1. `[mouth]月工作报表-网络中心-[name].docx`
2. `[mouth]月绩效考核表网络中心[name][yyyymmdd].docx`
3. `网络中心[mouth]月工时记录表.xlsx`
4. `网络中心[mouth]月排班表.docx`
5. `网络中心月工资考核表 --[mouth]月 .docx`

兼容历史模板的 `[mouth]` 拼写；导出结果不得残留占位符。工时表沿用参考文件的成员横向区块并增加签到明细，系统工时统一使用 `h`。工资考核工作量默认取系统工时且允许编辑。排班 DOCX 转换导入的正式排班 Excel 表格。
