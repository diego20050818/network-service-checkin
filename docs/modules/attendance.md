# 签到模块

签到服务是工时事实的唯一写入口。普通签到要求当前时刻在半开区间 `[开始, 结束)`；人工补记必须关联现有席位。临时替班只写实际人员字段。更正、撤销和恢复保存前后值与时间，不建立虚假的操作者身份审计。

签到首页每 30 秒刷新当天全部班次。只有当前班次可操作，卡片显示原负责人、签到进度和距结束倒计时；未开始和已结束班次保留在当天视图中。

请假只允许关联正式班次中已安排且未签到的席位。无代班请假不可签到并从到岗率分母剔除；指定代班后只能由该成员签到，签到后必须先撤销签到才能修改或撤销请假。加班使用相同签到记录链路和半开区间边界，完成签到或人工补记后才产生完整计划时长的计薪记录。办公人员是单次班次的手工席位。

审查记录见 `docs/reviews/attendance-review-20260906.md`。
