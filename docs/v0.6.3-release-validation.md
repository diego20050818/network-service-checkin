### 班次时段

- 解析器保留 Excel 明确填写的时间，不再按“上午/下午”覆盖；09:00–12:00 往返解析通过。
- 七条设置逐项校验时间格式、结束晚于开始和同类重复；工时由时间差计算。
- 同步仅更新未开始、无签到历史、来自正式排班且仍匹配旧设置的班次；历史、进行中、手工班次和人工改时班次保持不变。
- 冲突会给出具体原因并回滚整个设置保存；安全同步保留班次、席位和请假 ID，只更新时间、工时和 revision。
- 下载模板按当前设置动态生成，生成后重新解析通过；随包静态模板使用相同默认值。

### 日历、签到和提醒

- 周视图与 FullCalendar 共用人员/班次状态计算：未开始灰、全部处理绿、开班后有未签到红、请假琥珀；混合班次逐人展示 `✓`、`×`、`○`、`—`。
- 签到页显示当前班结束倒计时；首次加载优先定位最早当前班，无当前班时定位最近下一班；折叠后仍显示每人结果。
- 15 分钟提醒覆盖 14:59/15:00 边界、全部签到、全部请假、已结束、重启去重、过期清理和多班合并。
- 前台提醒层及“去签到/关闭提醒”经过 Electron E2E；提示音使用内置 Web Audio。后台 Windows 通知、任务栏闪烁、通知点击恢复窗口经过主进程适配层测试，不抢焦点。
- 日历事件入场只改变透明度，避免短事件在 220ms 动效期间产生几何重叠；减少动态效果时关闭位移、缩放和脉冲。
